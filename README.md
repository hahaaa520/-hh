- **测试范围**：许可证、版权、包信息与文件扫描结果
- **报告文件**：[F250117-f25011306-华心怡-作业1.docx](F250117-f25011306-华心怡-作业1.docx)

## 报告摘要

本次采用“固定版本 → 工具全扫 → 零命中复核 → 风险分级 → 整改复扫”的测试策略，并记录安装环境、原始命令、扫描摘要与剩余风险。

主要结论：

1. 测试时项目根目录缺少 `LICENSE`、`COPYING` 或 `NOTICE`，不能将扫描零命中理解为进入公有领域或许可合规。
2. 版权、作者和持有者信息不足，需要在确定许可证后补充归属与许可边界。
3. 未发现第三方包冲突证据，但这不等于完成兼容性证明；新增字体、图标、代码片段或 npm 包时仍需记录来源和许可义务。
4. 二进制文件未扫描属于剩余风险，最终结论仍需结合素材来源与人工核对。

完整环境、命令、证据说明和整改建议以报告原文为准。当前仓库仅收录报告文档，未收录报告中提到的原始 JSON、HTML 和运行日志。
